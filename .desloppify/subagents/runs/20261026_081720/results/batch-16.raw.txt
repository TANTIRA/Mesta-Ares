    "initialization_coupling": {
      "dimension_character": "Structurally this is a clean Rust workspace: there is no mutable module-scope state at all, the only statics are two lazily initialized pure values, and every service builds its state in `main` and injects it as `Arc<AppState>`/`Arc<Deps>`, so a developer can import any crate without worrying about import-time side effects or boot ordering. The fragility sits one layer up, at the seam between boot and runtime: configuration is resolved in two competing planes (boot-time `ConnectorConfig` versus per-call `env::var` with different empty-string semantics), the safety-critical kill switch has two implementations that disagree on edge cases, and table/schema ownership is documented per crate but implemented inside service binaries - including an `audit_log` table that nothing ever creates.",
